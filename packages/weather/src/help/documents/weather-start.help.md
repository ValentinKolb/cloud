Weather tracks saved locations and shows current conditions, hourly forecast, daily forecast, and rain radar.

## Overview {icon="layout-grid"}

:::reference
- **Saved location:** A city saved to your account with name, state, latitude, and longitude.
- **Forecast:** The location page shows current weather, hourly values, daily forecast, and rain radar.
- **Display link:** Display opens a public monitor view that refreshes automatically.
- **Admin settings:** Admins control default widget coordinates, cache duration, and the geocoding endpoint.
:::

## Use Weather {icon="route"}

:::reference
- **Add a location:** Search for a German city, select a result, and Weather saves its coordinates to your account.
- **Start from an empty overview:** When no location is saved, the overview explains the empty state and provides Add Location without requiring a forecast to be selected.
- **Read a forecast:** Open a saved location for current conditions, hourly forecast, daily forecast, details, and rain radar.
- **Open a display:** Use Display to choose zoom, light or dark theme, and a simple or detailed view.
- **Remove a location:** Remove deletes the saved location from your account and returns to the Weather overview.
:::

:::info Data scope
Location search is limited to German cities in the current UI. Forecast data can be unavailable when the configured provider has no data for the selected coordinates.
:::
